## Lessons from the hardened handoff

- Atomic evidence written through `mktemp` must be changed to mode `0644`
  before rename so host-side checksum verification remains possible after a
  root-owned container run.
- Bundle packaging must validate the current-record pointer, immutable run
  manifest, complete `SHA256SUMS` chain, qualified binary hash, and shared
  profile hash before rebinding them to a registry reference.
- A registry manifest digest and a local image/config digest are different
  identities. Both must be recorded, and the remote manifest's config digest
  must match the qualified local image ID.
- SSH host keys must be generated when the ephemeral pod starts, never baked
  into a reusable or publicly reachable image. A registry expiry is not cloud
  cleanup; exact-ID stop/delete and a final absence listing remain mandatory.
- Replaying a content-hashed bootstrap on a pinned CUDA base image can avoid a
  large custom-image upload, but it does not satisfy the present same-image
  contract without an explicit plan change and fresh host qualification.
