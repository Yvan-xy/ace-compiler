## Lessons learned

- Restore stage profiling through direct-codegen-aware instrumentation before
  making the next body-level optimization claim.
- The next runtime target should be parameter-general stage-level moved-rotate
  grouping, followed by `dual_evalmod`.
- `Pt_from_msg` / `Copy_plain` should not be treated as the next bottleneck on
  the ct-encoded path unless a future profile says otherwise.
- `perf` is not currently usable in the container because the host kernel tools
  for `6.8.0-117` are missing.
