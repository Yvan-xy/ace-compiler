## Work done

- Removed the generated `bootstrap_full` rtlib implementation mode and made
  `ace_edsl/examples/bootstrap_full.py` primitive-only.
- Removed `_skip_preprocessor` from `bootstrap_full`, so the top-level kernel
  now runs through the AST preprocessor.
- Fixed `range_dynamic` loop-carried accumulator emission so accumulator stores
  are emitted inside the AIR `do_loop` body before `new_loop_end()`.
- Added a script-level guard in `ace_edsl/tests/test_ckks_loop.py` to fail if a
  loop-carried accumulator store appears after `do_loop`.

## Takeaways

- Removing rtlib mode removes the original reason for skipping preprocessing in
  `bootstrap_full`.
- Enabling preprocessing on `bootstrap_full` does not by itself reduce
  primitive bootstrap AIR size, because the meaningful bootstrap loops live in
  ordinary helper functions in `bootstrap_decomposition.py`, not in the
  decorated kernel body.
- `range_dynamic` is now less broken for loop-carried values, but meaningful
  bootstrap loops are still poor candidates because they rely on Python lists,
  per-iteration constants, and Python-int rotations.
- `range_dynamic` can lower a simple CKKS loop through the current pipeline, but
  moddown/modswitch hoisting over bootstrap loops still needs backend
  loop-aware CKKS/poly analysis and optimization work.

## Runtime scalar loop bounds

- Added `range_dynamic` support for runtime scalar stop bounds with constant
  start and unit step, targeting loops like `range_dynamic(0, n)`.
- Added a dynamic range-loop builder binding that emits AIR `do_loop` compare
  expressions against the runtime bound node instead of folding the stop to an
  integer constant.
- Relaxed backend loop analyses to carry unknown trip counts conservatively for
  dynamic upper bounds.
- Fixed mixed ciphertext/scalar function signatures to reuse complete FHE
  record types, avoiding incomplete duplicate `CIPHERTEXT`/`PLAINTEXT` types in
  CKKS/poly lowering.
- Focused validation: `python3 ace_edsl/tests/test_ckks_loop.py` passed with
  runtime-bound lowering through raw AIR, CKKS, poly, and poly2c.

## Runtime scalar loop starts

- Extended `range_dynamic` to support runtime scalar start bounds as well as
  stop bounds, while keeping `step` as compile-time unit stride.
- Added AIR builder bindings for `range(dynamic_start, constant_stop)` and
  `range(dynamic_start, dynamic_stop)`.
- Relaxed context-parameter analysis, data-flow frequency analysis, and AIR op
  stats to treat dynamic loop starts as valid operands with unknown static trip
  count.
- Focused validation: `python3 ace_edsl/tests/test_ckks_loop.py` passed 9/9,
  including raw AIR and CKKS/poly/poly2c coverage for dynamic start/stop loops.
